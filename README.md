Vice Bay is a top-down open-world crime game that runs in a desktop browser: explore a living city on foot or by car, steal cars, outrun the police as your wanted level rises, and work through a story of missions.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
